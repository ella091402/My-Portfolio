# Portfolio Project

This repository contains a personal portfolio website for a female IT student and volleyball athlete.

## Features
- Light theme with neon red and purple accents
- Dark‑mode toggle
- Responsive layout (mobile, tablet, desktop)
- Sticky navigation bar
- Hero section with dynamic athlete image
- Sections: About, Skills, Projects, Experience, Achievements, Contact
- Interactive project cards
- Downloadable CV
- Subtle scroll animations

## Build & Deploy
1. Open `index.html` in a browser to view locally.
2. To publish on GitHub Pages, push the `portfolio` folder to a GitHub repository and enable GitHub Pages from the repo settings.
